chessdev.org is a reference guide for building chess engines.

All articles are reviewed by maintainers through pull requests. Each page frontmatter includes author, reviewer, and verification details.

## Topics covered

- Board representations and square indexing
- Move generation and position state updates (make/unmake)
- Search algorithms, pruning, and move ordering
- Evaluation functions and neural network evaluation (NNUE)
- Endgame tablebases and probing
- Engine protocols (UCI) and infrastructure

## How to contribute

Read the [contribution guide](/contribute/). Update existing articles when possible, or open a new page to introduce new topics.
