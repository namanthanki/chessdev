Reverse futility pruning, also known as static null move pruning, is a pruning method that prunes nodes based on whether
the static evaluation of the node beats beta by a sufficient margin. If so, we assume there exists at least one sequence
of moves that will preserve enough score to remain above beta, meaning the node can be pruned.

Such pruning methods are only sound in nodes that are not a PV node or in check. Furthermore, it is only applied in
sufficiently shallow nodes in order to prevent mate finding.

A basic implementation of reverse futility pruning is as follows:

```c
if (!is_pv && !in_check && static_eval - 128 * depth >= beta && depth <= 6) {
  return static_eval;
}
```

## Further improvements

There are more terms that could be added to reverse futility pruning in order to gain further elo, including but not
limited to:
 - Reducing the margin in nodes where the static evaluation has been improving over previous plies.
 - Using a quadratic function of depth rather than a linear one.
 - Interpolating the static evaluation with beta.
