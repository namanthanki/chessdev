# Notes

- Built with Astro and Starlight for documentation navigation, search, MDX, and dark mode.
- TypeScript is pinned to `6.0.3` for compatibility with `@astrojs/check`.
- Edit links in `astro.config.mjs` point to `https://github.com/namanthanki/chessdev`.
- Cloudflare Pages deployment requires `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets in GitHub.
- Example articles use placeholder author and reviewer handles.
